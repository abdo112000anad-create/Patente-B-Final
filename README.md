# Patente B بالعربي — v61

تطبيق Capacitor لتعلّم أسئلة القيادة الإيطالية مع النص والترجمة العربية. رقم Android لهذه النسخة هو `versionCode 61` (`61.0.0`).

## الصوت والترجمة

يستخدم التطبيق Web Speech المدمج في النظام فقط، ولا يضم محرك TTS محليًا أو نماذج صوت أو مكتبات Piper/ONNX. يطلب النطق باللغة الإيطالية `it-IT`؛ إذا لم تكن الأصوات جاهزة، ينتظر تغيّر قائمة الأصوات ويحاول مجددًا بعد 500 مللي ثانية، ثم يطلب `it-IT` من محرك النظام حتى إن لم يعرض صوتًا إيطاليًا مسمى. بقي النص العربي والترجمة، وأزيلت أزرار ووظيفة الاستماع العربي. أضيفت ترجمات مباشرة للصيغ والـlemmas الأساسية الناقصة في الدروس الاثني عشر المعدلة، ومنها `distingue` و`distinguere`.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس إصدار متجر Play. سرعة Web Speech الإيطالية `rate=0.8` و`pitch=1.0`. يرفع GitHub Actions الـ APK كـ artifact باسم `patente-b-v61-debug-apk` بعد نجاح اختبارات JavaScript وAndroid والتحقق من خدمات النطق في manifest.
