# Patente B بالعربي — v52

تطبيق Capacitor لتعلّم أسئلة القيادة الإيطالية مع الترجمة العربية. رقم Android لهذه النسخة هو `versionCode 52` (`52.0.0`).

## الصوت

يستخدم التطبيق Web Speech المدمج في المتصفح فقط، ولا يضمّ محرك TTS محليًا أو نماذج صوت أو مكتبات Piper/ONNX. زر الاستماع في صفحة الدرس ينطق الإيطالية بصوت النظام الإيطالي وبسرعة 0.8، مع انتظار تحميل الأصوات على Android. كما أن شرح مراحل الدرس يُقرأ بالإيطالية.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس إصدار متجر Play. يدفع سير GitHub Actions الإصدار التالي إلى Artifact باسم `patente-b-v52-debug-apk` بعد نجاح الاختبارات والبناء.
