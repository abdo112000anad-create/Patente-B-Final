# Patente B بالعربي — v66

تطبيق Capacitor لتعلّم منهج رخصة القيادة الإيطالية B بالإيطالية مع شرح وترجمة عربية. رقم Android لهذه النسخة هو `versionCode 66` (`66.0.0`). تحافظ النسخة على المنهج المحدّث ذي 50 درسًا، وتضم رسوماً تعليمية SVG داخلية لكل درس، وتحوّل تشغيل الصوت في تطبيق Android إلى محرك تحويل النص إلى كلام الذي اختاره نظام الهاتف.

## الصوت والترجمة

يستخدم تطبيق Android الأصلي `android.speech.tts.TextToSpeech` ويهيّئ المحرك الافتراضي للنظام للغة `it-IT` قبل أول تشغيل. تُثبّت إعدادات النطق على السرعة `0.8` والنبرة `1.0`، ويُوقف الصوت الجاري عند الإيقاف أو تغيير الشاشة. لا يوجد fallback إلى Web Speech، ولا تُضمّن نماذج صوت أو مكتبات TTS داخل الحزمة. يستخدم التطبيق محرك TTS المحدد في إعدادات Android؛ إذا لم يتوفر صوت إيطالي، نزّل بيانات اللغة الإيطالية من إعدادات تحويل النص إلى كلام في الهاتف ثم جرّب مجدداً. لا يمكن للتطبيق فرض تحديث المحرك أو اختيار مزود غير محدد في إعدادات النظام. تشغيل الصوت الأصلي خاص بتطبيق Android؛ نسخة الويب لا تستخدم محرك متصفح بديلاً.

حدّث v62 قاموس المفردات الأساسية للدروس الجديدة، بما فيها مصطلحات الأولوية والطوارئ ومستخدمي الطريق والرجوع للخلف والطريق السريع. وتُعامل الترجمات السياقية الملتبسة وفق معنى سياق القيادة، لا بمعنى حرفي قد يضلل المتعلم.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس حزمة نشر Play موقعة. يرفع GitHub Actions الـ APK كـ artifact باسم `patente-b-v66-debug-apk` بعد نجاح اختبارات JavaScript وAndroid والتحقق من إعلان خدمة TTS في manifest. يتضمن هذا المصدر إضافة Android الأصلية في `native/android/src/main/java/it/patenteb/sideload/v29/NativeTtsPlugin.java`؛ ينسخها سكربت البناء إلى مشروع Android قبل التجميع.
