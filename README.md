# Patente B بالعربي — v62

تطبيق Capacitor لتعلّم منهج رخصة القيادة الإيطالية B بالإيطالية مع شرح وترجمة عربية. رقم Android لهذه النسخة هو `versionCode 62` (`62.0.0`). يستبدل الإصدار محتوى الدروس `u4-l1` إلى `u6-l4` بالمحتوى المحدّث مع الإبقاء على بقية الدروس، ليظل المنهج 50 درسًا.

## الصوت والترجمة

يستخدم التطبيق Web Speech المدمج في النظام فقط، ولا يضم محرك TTS محليًا أو نماذج صوت أو مكتبات Piper/ONNX. قبل النطق، يهيّئ محرك الصوت مرة واحدة بمقطع إيطالي فارغ ثم يلغيه؛ وإذا لم تظهر الأصوات، يفحص قائمة أصوات النظام كل 200 مللي ثانية، مع إتاحة إلغاء الانتظار عند إيقاف الصوت. يختار صوتًا إيطاليًا عند توفره، وإلا يطلب `it-IT` من محرك النظام. يبقى النطق إيطاليًا فقط بسرعة `0.8` ودرجة `1.0`، والنص العربي والترجمة متاحان للقراءة.

حدّث v62 قاموس المفردات الأساسية للدروس الجديدة، بما فيها مصطلحات الأولوية والطوارئ ومستخدمي الطريق والرجوع للخلف والطريق السريع. وتُعامل الترجمات السياقية الملتبسة وفق معنى سياق القيادة، لا بمعنى حرفي قد يضلل المتعلم.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس إصدار متجر Play. يرفع GitHub Actions الـ APK كـ artifact باسم `patente-b-v62-debug-apk` بعد نجاح اختبارات JavaScript وAndroid والتحقق من خدمات النطق في manifest.
