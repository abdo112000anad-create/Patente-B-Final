# Patente B بالعربي — v69

تطبيق Capacitor لتعلّم منهج رخصة القيادة الإيطالية B بالإيطالية مع شرح وترجمة عربية. رقم Android لهذه النسخة هو `versionCode 69` (`69.0.0`). تحافظ النسخة على المنهج المحدّث ذي 50 درسًا، وتضم رسوماً تعليمية SVG داخلية لكل درس، وتحوّل تشغيل الصوت في تطبيق Android إلى محرك تحويل النص إلى كلام الذي اختاره نظام الهاتف.

## الصوت والترجمة

يستخدم تطبيق Android الأصلي `android.speech.tts.TextToSpeech` ويهيّئ المحرك الافتراضي للنظام للغة `it-IT` قبل أول تشغيل. تُثبّت إعدادات النطق على السرعة `0.8` والنبرة `1.0`، ويُوقف الصوت الجاري عند الإيقاف أو تغيير الشاشة. لا يوجد fallback إلى Web Speech، ولا تُضمّن نماذج صوت أو مكتبات TTS داخل الحزمة. يستخدم التطبيق محرك TTS المحدد في إعدادات Android؛ إذا لم يتوفر صوت إيطالي، نزّل بيانات اللغة الإيطالية من إعدادات تحويل النص إلى كلام في الهاتف ثم جرّب مجدداً. لا يمكن للتطبيق فرض تحديث المحرك أو اختيار مزود غير محدد في إعدادات النظام. تشغيل الصوت الأصلي خاص بتطبيق Android؛ نسخة الويب لا تستخدم محرك متصفح بديلاً.

حدّث v62 قاموس المفردات الأساسية للدروس الجديدة، بما فيها مصطلحات الأولوية والطوارئ ومستخدمي الطريق والرجوع للخلف والطريق السريع. وتُعامل الترجمات السياقية الملتبسة وفق معنى سياق القيادة، لا بمعنى حرفي قد يضلل المتعلم.

## البناء والاختبارات

المتطلبات: Node.js 22، Java 21، Android SDK Platform 36. نفّذ:

```bash
npm ci
npm test
bash ./scripts/build-android.sh
```

ينتج البناء المحلي APK تشخيصيًا موقّعًا بمفتاح debug، وليس حزمة نشر Play موقعة. يرفع GitHub Actions الـ APK كـ artifact باسم `patente-b-v69-debug-apk` بعد نجاح اختبارات JavaScript وAndroid والتحقق من إعلان خدمة TTS في manifest. يتضمن هذا المصدر إضافة Android الأصلية في `native/android/src/main/java/it/patenteb/sideload/v29/NativeTtsPlugin.java`؛ ينسخها سكربت البناء إلى مشروع Android قبل التجميع.

يفحص سكربت البناء وCI بصمة شهادة APK ويمنعان تمرير نسخة تختلف عن شهادة v64/v65. يستخدم البناء المحلي مفتاح Android debug المتاح، أو مفتاحاً يحدده `PATENTE_DEBUG_KEYSTORE` مع متغيرات كلمة المرور والاسم الموضحة في إعداد Gradle؛ لا تضع ملف المفتاح أو كلمات مروره في المستودع. يستخدم CI سر GitHub Actions باسم `PATENTE_DEBUG_KEYSTORE_B64`، يفكّه مؤقتًا خارج المستودع بصلاحيات مقيدة ويحذفه عند انتهاء خطوة البناء. يفشل البناء إذا غاب السر أو لم تتطابق شهادة APK؛ لا يعني اجتياز فحص الشهادة نجاح Firebase أو اختبار التشغيل.

### تحقق Firebase قبل إصدار سحابي فعّال (اختياري)
يتضمن `android/app/google-services.json` الإعداد الرسمي للمشروع `patente-b-arabic` وعميل Android للحزمة `it.patenteb.sideload.v29`. كما يحتوي `src/firebase-config.mjs` إعداد SDK العام لتطبيق Web مسجّل في المشروع نفسه؛ أُدرجت حقول العميل العامة فقط، من دون بيانات حساب خدمة أو مفاتيح خاصة. شغّل `npm run check:firebase:production` لفحص شكل الإعدادات وتطابق المشروع ورقم المرسل والحزمة. نجاح الفحص لا يفعّل خدمات Firebase ولا يغيّر موفري المصادقة أو قواعد Firestore.

هذا فحص اتساق شكلي فقط، وليس إثباتاً لاتصال Firebase أو جاهزية نشر: لا يتحقق من إعداد OAuth أو نطاقات/معرّفات العملاء أو تفعيل Firebase Authentication وموفريه، ولا يراجع Firestore Security Rules أو اختبارها. لا يغيّر هذا الأمر بناء الضيف أو CI؛ يبقيان debug فقط، ولا يجوز اعتبار نجاحه وحده موافقة إصدار أو دليلاً على سلامة قواعد الوصول.
